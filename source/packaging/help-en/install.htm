Installation

  1. Close SolidWorks and make sure no SLDWORKS process is still running.
  2. Run the SWTool installer as administrator.
  3. After install, run the SolidWorks add-in registration step if the installer did not do it automatically.
  4. Open SolidWorks and check that the SWTool ribbon/menu is visible.

Moving the install folder

Close SolidWorks and SWTool before moving the folder. After moving, run the SolidWorks add-in registration step from the new location.

Upgrading

Close SolidWorks and SWTool before upgrading. It is recommended to back up the settings file before an upgrade.
