SWTool feature overview

SWTool works with SolidWorks assemblies, bill of materials (BOM), component properties, templates and batch file operations.

Main capabilities

  • load data from the active SolidWorks assembly;
  • edit component properties and save the changes back into SolidWorks;
  • export and print BOM reports through templates;
  • file-level operations on assembly files: copy, rename, redirect references;
  • demo mode and per-machine licence activation.
