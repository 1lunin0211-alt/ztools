Activation and licence transfer

Getting an activation code

  1. Open the SWTool activation window.
  2. Copy the licence key issued for your purchase.
  3. Provide a transfer password. The password must be 8 to 64 characters: Latin letters and digits.
  4. Click Activate. The code is checked against the current machine.

If you do not have an activation code yet, contact your SWTool reseller and provide the licence details for this machine. Do not use a key from another customer: the licence is bound to the hardware.

Demo mode

If no licence is active you can run SWTool in demo mode. When the demo timer expires, SWTool closes; SolidWorks itself is not blocked by the missing key.

Transferring a licence

  1. On the old machine, run ZTool License Deactivate.exe.
  2. Enter the transfer password and confirm deactivation.
  3. Save the transfer data and use it when creating a new activation.
  4. On the new machine, perform the normal SWTool activation flow.
